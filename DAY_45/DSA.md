# Day 45: 2 February 2026 - Binary Tree Foundations

## 🌳 Introduction to Trees
- **Definition:** A non-linear, hierarchical data structure consisting of nodes connected by edges.
- **Key Terms:** - **Root:** The topmost node.
  - **Leaf:** Nodes with no children.
  - **Height:** Longest path from root to a leaf.
  - **Depth:** Path from root to a specific node.

## 🛠️ Implementation
- Created a `Node` class with `data`, `left`, and `right` pointers.
- Mastered **Pre-Order Traversal** (Recursive):
  1. Visit Root
  2. Visit Left Subtree
  3. Visit Right Subtree

## 💡 Why Trees for Placements?
- Used in DOM (Web), File Systems (OS), and Databases (Indexing).
