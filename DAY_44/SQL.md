# Day 44: 1 February 2026 - SQL Milestone

## 🔑 Interview Focus Areas
- **Normalization:** 1NF, 2NF, 3NF, BCNF (No partial or transitive dependencies).
- **Window Functions:** RANK(), DENSE_RANK() for placement leaderboards.
- **ACID Properties:** Atomicity, Consistency, Isolation, Durability.
- **TCL Commands:** COMMIT and ROLLBACK for secure transactions.

## ⚡ SQL Speedrun
- **Union vs Union All:** Union removes duplicates, Union All is faster.
- **Indexing:** Improves SELECT performance but adds overhead to INSERT/UPDATE.
